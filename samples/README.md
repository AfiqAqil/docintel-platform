# Synthetic sample documents

All documents in `out/` are fictional (architecture assumption 8): invented people, an
invented insurer, and addresses and phone numbers drawn from ranges reserved for fiction
(`example.com`, the UK's `07700 900xxx` range). Generated by `generate.py`, deterministically:
re-running it produces byte-identical output for every file. `corrupt_encrypted.pdf`'s
password is fixed but not published here.

Run with:

```
python samples/generate.py --out samples/out
```

## Samples

| File | Format | Exercises |
|---|---|---|
| `claim_form_complete.pdf` | PDF, real text | Happy path. Every `ClaimFormExtraction.REQUIRED_FIELDS` value present and valid. Outcome `COMPLETE` |
| `claim_form_incomplete.pdf` | PDF, real text | Claim reference and claimed amount omitted entirely. Outcome `INCOMPLETE` |
| `claim_form_bad_dates.pdf` | PDF, real text | Date of incident after date filed, the one cross-field rule in `validate.py`. Triggers a validation error and the retry cycle |
| `invoice_repair.pdf` | PDF, real text | Invoice extraction. 4 line items summing exactly to the stated total, one amount with a thousands separator |
| `policy_document.docx` | DOCX | `python-docx` reading path and the generic extractor. Paragraphs plus a coverage table, since table cell text is read separately from paragraphs |
| `customer_correspondence.docx` | DOCX | Generic extractor on prose. A complaint letter about a claim |
| `identity_card.png` | PNG | Image path, no text layer. Snippet verification is skipped. Card layout with fields rendered as pixels |
| `damage_photo.jpg` | JPG | Supporting evidence. A standalone synthetic scene, not a document scan |
| `claim_form_scanned.pdf` | PDF, image only | `pypdfium2` render path. The complete claim form rendered to an image and embedded as a full page PDF with no text layer |
| `restaurant_menu.pdf` | PDF, real text | Out of scope document type. Classification routes to `UNSUPPORTED` |
| `corrupt_encrypted.pdf` | PDF, encrypted | Unreadable, terminal failure, status `FAILED` |
